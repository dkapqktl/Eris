[공격 능력치]
1. 물리 공격력 : 공격력 만큼 상대방에게 물리 대미지를 줌, 스테이터스 힘(힘 * 3)과 민첩(민첩 * 1)에 따라 공격력이 추가됨
2. 마법 공격력 : 공격력 만큼 상대방에게 마법 대미지를 줌, 스테이터스 지능(지능 * 5)에 따라 공격력이 추가됨
3. 관통력 : 방어력 - 관통력 으로 방어력 차감 후 받는 피해 감소 계산, 방어력이 음수가 된다면 나누기 2를 한 후 받는피해 감소량 계산(받는 피해가 반대로 늘어남), 민첩에 따라 관통력 증가
4. 크리티컬 확률 : 크리티컬이 터질 확률, 스테이터스 민첩(민첩 * 0.2)에 따라 확률 증가, 최대 100%
5. 크리티컬 배수 : 기본값은 175%, 아이템등으로 더 올릴 수 있음, 스테이터스 민첩(민첩 * 0.1)에 따라 배수 증가
6. 공격 사거리 : 공격 사거리 수치만큼 공격 범위 변경
7. 공격 속도 : 공격을 얼마나 자주 할 수 있는지의 수치
8. 히트 수 : 한번 공격할때 몇번을 공격할지, 무기와 스킬로만 히트 수를 정함
9. 생명력 흡수 : 상대에게 HP에 준 최종 데미지의 %만큼 체력 회복, 무기 스킬 버프로만 올릴 수 있음

[참고 사항 & 상세 설정]

1. 물리,마법 공격력
- 플레이어는 스테이터스모듈이 있음 스테이터스에 따른 공격력 변경 시스템이 있음
몬스터는 어텍모듈은 있되 스테이터스모듈이 없을 예정이라 고려해서 제작 필요
- 구성 의도 : 물리와 마법을 나누어둔 이유는 상황에 따라 물리와 마법피해 면역 혹은 대미지감소를 만들어 게임의 다채로움을 만들기 위함


2. 관통력
- 관통력은 방어력 - 관통력 을 한 후 피핵감소량 계산
ex 1) 방어력 20 - 관통력 10 = 방어력 10 으로 디펜스모듈에서 피해감소량 계산
- 방어력 - 관통력 이 음수가 될 경우 나누기 2를 함(피해량 증가량이 너무 높아지는 상황 방지)
ex 2) 공격력 100 일때 관통력 60 - 방어력 10 = 50 / 2 = 25 / (150 + 25) = 0.14 * 공격력 100 = 14의 추가 데미지

디펜스모듈 에 있을 함수 내용 예시
public float DamageReduction(float damage, float penetration)
{
float finalDamage;
float finalDefence;

if (targetDefence < penetration)
{
finalDefence = (( penetration - targetDefence) / 2 );
finalDamage = damage + ( damage * ( finalDefence / ( 150 + finalDefence )));
return finalDamage;
}

else if (targetDefence > penetration)
{
finalDefence = targetDefence - penetration;
finalDamage = damage - ( damage * ( finalDefence / ( 150 + finalDefence )));
return finalDamage;
}

else
{ 
return damage;
}
}

- 만랩까지 전부 민첩에 투자할때 50%의 크리티컬 확률, 나머지는 아이템 및 스킬과 버프로 채우게 할 예정

criticalChance

5. 공격 사거리
공격 방식마다 적용이 다르게 되어야 하기 때문에 아래 공격 방식에서 같이 다룰예정

6. 공격 속도
- 근접 공격의 경우 공격을 더 자주함
- 활의 경우 화살을 더 자주 발사함, 화살의 속도는 변함 없음, 화살의 속도는 투사체 속도로 할 예정
- 마법 공격의 빨라지며 공격을 더 자주함
- 캐스팅이 필요한 것들은 캐스팅 속도가 빨라짐
* 활에 차징을 만들꺼라면 클릭 유지시 차징 완료되면 자동 발사 or 마우스 때야지 발사 트리거를 옵션으로 만들어야 함

7. 히트수
- 기본 히트수는 1
- 방식이 2가지 존재
- 1번째는 히트박스에 히트수가 2번이라면 닿을때 1번째 데미지, 이후 같은 대상에게는 0.1초 간격? 정도로 1번 더 데미지 죽기
- 2번째는 히트수가 2번이라하면 히트박스를 껏다 켯다를 2번 하기 -> 검처럼 휘두르는거엔 애매함, 그래서 추후 공격버튼 누르면 애니매이션 나오고 범위 안에 있으면 공격 맞게하기 방식 고려
- 3번째는 다중공격 일 경우 각 히트박스에 닿으면 데미지 받기
- 특정 악세사리를 끼면 데미지가 감소하고 히트수가 바뀔 수 있음
- 무기마다 히트수가 다를 수 있음
- 스킬마다 히트수가 다를 수 있음

* 중요한점 : Hit와 Status Proc를 분리하여 5연타 공격 혹은 화살을 3개 발사 등 한 콜라이더 혹은 한 캐릭터가 여러 콜라이더에 여러번 데미지를 받더라도 상태이상은 1번만 부여가 됨
다만 예외의 경우도 필요, 특정 무기 혹은 특정 스킬등은 상태이상을 여러번 줄 수도 있도록 확장성을 위해서


8. 생명력 흡수
- 공격시 데미지를 주었을때 공격력에서 흡수율에 따른 체력회복
float lifeStealAmount = finalDamage * lifeStealPercent;
HP.Heal(lifeStealAmount);

* 중요한점 : 단일 공격이나 범위가 좁은 공격은 100%, 광역공격은 50%, 화상과 독같은 도트데미지는 0%

02. 젖음(물): 지속시간 동안 이동속도, 공격속도 10% 씩 감소, 1스택 추가 마다 1% 증가, 최대 10스택, 다만 일반몬스터 100%, 네임드몬스터 50%, 보스에겐 미적용
03. 감전(전기) : 지속시간 동안 받는 대미지 1.15배 증가, 최대 3스택이며 3스택이 되었을때 2초간 기절, 감전 최대 지속시간 5초, 감전 지속 시간이 끝난 대상은 3초간 감전 상태이상 및 스택 무시, 다만 일반몬스터 1.15배 네임드몬스터 1.1배 보스에겐 1.05배 데미지를 주며, 보스에겐 기절 미부여
04. 빙결(얼음) : 지속시간 동안 행동 불능(동결), 지속시간 동안 데미지를 받을시 1.5배의 데미지를 받고 즉시 동결 해제, 동결 상태에서 풀린 대상은 5초간 동결되지 않음, 빙결 최대 5스택, 다만 5스택 일시 다시 한번 동결 되며 데미지 받을시 1.75배의 데미지를 받고 즉시 동결 해제(5스택 동결), 5스택 동결 해제 후 5초간 동결 되지 않으며 빙결 스택 무시, 다만 보스는 빙결 상태이상 무시
05. 중독(자연) : 지속시간 동안 1초 마다 공격자의 공격력 0.15의 고정데미지, 중독 상태이상에 걸린 상태에서 더 높은 공격력을 가진 캐릭터에게 중독 상태이상이 들어온다면 공격력이 더 높은것으로 데미지를 계산, 최대 10스택, 1스택당 0.05씩 증가된 데미지를 받음, 다만 보스에겐 스택 미적용

[기타 상태이상 종류(보스에겐 미적용)]
01. 실명 : 지속시간 동안 공격력과 크리티컬 확률이 30% 감소
02. 매혹 : 지속시간 동안 컨트롤 불가능, 이동속도 70% 감소 + 가장 가까운 적에게 이동
03. 광란 : 지속시간 동안 컨트롤 불가능, 가장 가까운 캐릭터를 찾아 공격, 공격력이 20% 증가, 받는피해는 30% 증가
04. 혼란 : 지속시간 동안 컨트롤 불가능, 1초마다 랜덤한 좌표로 이동(순간이동이 아닌 움직임)
05. 처형 : 지속시간 이후 죽음, 시전자 사망시 해제, 아이템등으로 해제 가능
06. 기절(무) : 지속시간 동안 행동 불능
07. 슬로우(무) : 지속시간 동안 이동속도 (%) 감소(시전자의 옵션마다 퍼센트 다름)
08. 속박 : 지속시간 동안 공격이나 스킬 사용등은 가능하나 움직임 혹은 움직임에 관련 된 스킬은 불가능
* 기타 상태이상 공통 : 지속시간이 끝나기 전까지 같은 상태이상은 무시(중복 무시), 지속시간 끝난 후 5초간은 같은 상태이상 무시
* 확장성 : 위 기타 상태이상 공통을 무시 혹은 무시 시간이 더 짧은 캐릭터도 있음(ex. 보스)

추후 확장성 필요

[상태이상 시너지 효과]
1. 화상 상태 일때
- 화상 효과 : 1스택 증가, 화상 지속시간 2초 증가, 최대스택일 경우 지속시간 증가 하지 않음
- 젖음 효과 : 화상 상태이상 즉시 해제, 젖음 상태이상 적용
- 감전 효과 : 화상 지속시간 1초 증가, 감전 상태이상 적용, 화상 데미지에 감전 추가데미지 미적용*
- 빙결 효과 : 화상 상태이상 즉시 해제, 빙결 상태이상 적용
- 나머지 : 화상 상태이상 유지, 해당 상태이상 적용

2. 젖음 상태 일때
- 화상 효과 : 화상 상태이상 무시, 젖음 상태이상 지속시간 2초 감소
- 젖음 효과 : 젖음 지속시간 2초 증가, 젖음 상태이상 1스택 추가
- 감전 효과 : 기절 상태이상 2초 적용(3스택 기절과는 다른 기절이라 중복 가능), 일정 범위 내에 젖음 효과중인 캐릭터가 있다면 감전 상태이상 적용(감전 전이)(감전 전이를 받은 대상은 감전전이를 하지 않음, 이미 감전 상태이상인 상태의 대상에겐 감전전이 X, 버그방지용(감전이 돌고도는 연쇄 반응 차단)), 감전 상태이상 추가피해 1.15 -> 1.25배로 적용
- 빙결 효과 : 젖음 상태이상 즉시 해제, 젖음 상태이상 스택 제거, 빙결 상태이상 적용, 빙결 지속시간 1.5배, 빙결 해제시 1.75배 데미지, 5스택 빙결일 시 2.0배 데미지
- 나머지 : 젖음 상태이상 유지, 해당 상태이상 적용

3. 감전
- 화상 효과 : 감전 상태이상 유지, 화상 상태이상 지속시간에 1초 추가하여 적용, 화상 데미지에 감전 추가데미지 미적용
- 젖음 효과 : 감전 상태이상 유지, 젖음 상태이상 적용, 일정 범위 폭팔데미지 1회
- 감전 효과 : 감전 1스택 증가, 감전 지속시간 2초 증가
- 빙결 효과 : 감전 상태이상 유지, 빙결 상태이상 적용, 감전 추가데미지에 빙결 파쇄 효과 적용(ex. 100의 공격력 -> 빙결 1.5배 : 150의 데미지 -> 감전 1.15배 : 172.5 의 최종 데미지)
- 나머지 효과 : 감전 상태이상 유지, 해당 상태이상 적용

4. 빙결
- 화상 효과 : 화상 상태이상 무시, 동결 해제, 이때 빙결 파쇄 효과 미적용, 젖음 상태이상 적용, 빙결 스택 제거, 젖음 상태이상 1스택 추가
- 젖음 효과 : 동결 상태일땐 젖음 상태이상 미적용, 이외 젖음 상태이상 적용
- 감전 효과 : 동결 상태일땐 감전 상태이상 미적용, 이외 감전 상태이상 적용
- 빙결 효과 : 1스택 증가
- 나머지 효과 : 기존 상태이상 유지, 해당 상태이상 적용

5. 중독
- 중독 : 1스택 증가
- 감전 : 감전 상태이상 적용, 중독 상태이상 유지, 중독 고정데미지에 감전 추가데미지 미적용
- 나머지 효과 : 기존 상태이상 유지, 해당 상태이상 적용

6. 기타 상태이상

- 광란 : 광란 상태이상 지속시간 중 매혹,혼란과 적용 불가, 나머지 기타 상태이상 적용 가능
- 혼란 : 혼란 상태이상 지속시간 중 광란,매혹과 적용 불가, 나머지 기타 상태이상 적용 가능

[공격하는 방향]
기본 베이스 : 마우스 커서방향으로 공격
자동 타게팅(공격) : 옵션에서 온오프 가능, 사거리 이내 마우스 방향으로 가장 가까운 적, 사거리 이내 없으면 타겟팅 안함
자동 타겟팅(자원) : 상시 발동도끼와 곡괭이는 사거리 이내 마우스 방향으로 가장 가까운 해당 자원에 자동 타겟팅, 사거리 이내 없으면 타겟팅 안함
ex)곡괭이 혹은 도끼로 자원 채굴할때(ex 네세스 자원 자동 타게팅 방식)

초보자들 혹은 필요로 하는 유저들을 지원하기 위한 옵션으로 자동타게팅 온오프를 통해 사냥을 편하게 할 수 있도록
이 방식은 유도 공격 혹은 리그오브레전드의 케넨 궁극기 처럼 사거리 내의 공격(체력이있는)을 받을 수 있는 오브잭트의 위치를 가져와 공격을 하는 방식

[피격 판정]
1. 투사체에 닿아야함
ex 1) 검의 공격범위가 부채꼴일 경우 검을 부채꼴 범위에서 휘두를때 캐릭터가 공격하는 방향 좌측에서 우측으로 휘두른다면 휘두를때 검에 닿아야 데미지를 받음
ex 2) 창의 공격 범위가 직선일 경우 캐릭터 앞쪽으로 창이 나갈때 창에 닿아야 데미지를 받음
ex 3) 활을 쏜다라고 하면 투사체를 앞으로 발사하는데 발사한 투사체에 닿아야 데미지를 받음
ex 4) 유도공격시 유도 투사체가 타겟을 찾아 따라가다 타겟에게 닿아야 데미지를 받음

2. 히트박스 온오프 방식
- 공격 트리거 발동시 히트박스가 온 되며 히트박스 안에있는 공격 받을 수 있는 오브잭트는 공격 받음

3. 즉시 공격
- 공격 사거리 안에 있다면 공격받을 수 있는 오브잭트 위치를 가져와 즉시 공격
* 마우스 커서 방향으로 플레이어와 가장 가까운 적, 2명 이상 공격시 가장 가까운 2명
* 공격 사거리 내에 있는 모든 적
* 랜덤일 경우 공격사거리 내에 있는 적중에 랜덤타겟
* 공격 사거리 내에 있는 가장 가까운 적, 2명 이상 공격시 가장 가까운 2명

[공격방식]

[근접] (최상 1점 / 상 2점 / 중상 3점 / 중 4점 / 중하 5점 / 하 6점 / 최하 7점) / 15점 맞추기
1. 부체꼴(예 : 검, 대검) : 데미지 중, 공격속도 중, 관통력 중, 넉백 중상
- 공격 사거리 증가시 각도는 고정이되 r의 길이가 늘어나서 총 면적이 늘어남
2. 직선(예 : 창) : 데미지 중, 공격속도 중상, 관통력 상, 넉백 하
- 공격 사거리 증가시 폭은 그대로, 길이만 늘어남
3. 공격자 앞 범위 공격(예 : 해머) : 공격력 최상, 공격속도 최하, 관통력 상, 넉백 상, 공격 딜레이(클릭하면 모션 뒤 1초뒤 공격 등)  혹은 차징을 만들 예정(3점), 상황에 따라 공격자 앞 범위는 사각형, 혹은 원형
- 공격 사거리 증가시 거리가 늘어난 만큼 원형의 크기가 커짐
4. 공격자 주변 원형(예 : 글레이브, 디아블로의 휠윈드 처럼) : 데미지 중하, 공격속도 최상, 관통력 중, 넉백 중하
- 공격 사거리 증가시 원이 커짐
5. 다중방향 : 직선 공격을 십자모양, 별보양, 삼지창 모양 등 다중방향으로 함

* 확장성 : 무기마다 공격 패턴이 다를수도 있음, 예를들어 1타 직선 2타 직선 3타 부체꼴
* 추후 확장성 : 여러 방식 더 생길 수도 있음

[원거리]
1. 마우스 방향으로 직선 투사체 발사 : 근접 직선공격과 마찬가지로 다중방향 확장성 필요
- 공격 사거리 증가시 투세체가 날아가는 거리가 늘어남
2. 관통 공격 : 발사한 투사체가 오브잭트를 맞추고 관통 수에 만큼 사라지지 않고 계속 날라감
- 공격 사거리 증가시 투세체가 날아가는 거리가 늘어남
3. 타겟 즉시공격 : 피격방식의 즉시공격과 동일함
- 공격 사거리 증가시 적 위치를 가져오는 원이 커짐
4. 유도공격 : 투사체의 일정 범위내에 적이 있다면 인식한 후 그 적을 따라가서 명중함, 이때 관통공격일 경우 대상이 안죽었다면 다시 따라가서 공격, 대상이 죽었다면 앞으로 그대로 날라감, 이때 투사체 범위 내에 적이 또 감지된다면 같은 작업을 반복함
5. 범위공격 : 투사체 발사 혹은 즉시공격으로 공격할때 공격이 성공하면 일정 범위에 피해를 줌, 투사체 공격일 경우 관통 공격이라면 범위공격은 관통한 적들은 모두 범위공격을 함, 이때 폭팔 범위에 폭팔 공격을 한 캐릭터가 있다면 해당 캐릭터는 폭팔 피해를 받으면 안됨, 다만 예외의 경우도 필요(예를들어 다이너마이트 경우 던진자도 공격을 받는다)
6. 유지공격 : 일정 범위에(직선,부체꼴,원형 등) 공격 트리거를 누르고 유지한다면 유지하는동안 해당 공격이 끊기지 않고 계속 나감, 예를들어 레이저나 화염방사기
7. 부메랑 : 일정 범위를 날아 간 후 사거리 끝에 도달하면 다시 플레이어에게 돌아옴
8. 다중 발사 : 여러 방향으로 투사체를 날림

* 중요성 : 투사체 속도와 투사체가 날아갈 사거리와 투사체 유지 지속시간이 있어야함
* 확장성 : 1번과 3번은 투사체 발사라고 적혀있지만 투사체 발사가 아닌 히트범위 온오프 형식의 원거리 공격이 있을 수 있음, 마치 근접공격의 직선공격을 히트박스 온오프식으로 한다 생각하면 됨
* 폭팔공격

[소환]
1. 플레이어 범위로 감지 : 플레이어 범위 내에 적이 있다면 감지 단계, 감지 후 적을 처치한 후 다른 적이 범위 내에 있다면 바로 타겟으로 지정 후 공격, 적이 없다면 플레이어에게 돌아옴
2. 소환수 범위로 감지 : 플레이어 범위 감지보다 소환수 범위 감지가 더 클수도 있음, 또한 플레이어 범위 감지로 적을 감지 후 적을 처치 후 플레이어 범위감지 내에는 적이 없지만 플레이어 감지 범위 밖에 적이 있는데 소환수 범위 안에 감지가 된다면 플레이어 감지 범위를 나가서 공격

* 확장성 : 근접 공격에 원거리 공격이 달릴 수 있음

[원거리 공격 중요한점]
1. 투사체를 맞는다면?
공격을 누가하는지를 공격 받은자가 알아야함
활이라면 투사체가 날아가는데 그 화살 투사체를 날린 캐릭터가 누구인지 알아야함
플레이어가 날린 화살이라면 몬스터는 공격대상을 화살이 아닌 플레이어로 인식해야함

2. 유도탄은 세부내용
플레이어가 쏜 유도탄은 피격 물체와 피격 엔피씨, 플레이어 본인을 인식하면 안되고 몬스터만 인식 후 유도하여 날아간 후 데미지를 줘야함(예외의 경우도 필요, 착용 장비나 스킬에 따라 본인을 제외한 피격 물체와 피격 엔피씨도 맞을 수 있음, 또한 광란에 걸릴경우 아군 엔피씨를 공격할 수도 있기에 아군 엔피씨에게 유도가 되어야함)

반대로 적이 쏜 유도탄은 피격 물체와 같은 몬스터를 인식하면 안되고 유도탄이 인식하는 사정거리 안에 플레이어가 있다면 플레이어에게 유도되어 데미지를 받아야함(예외의 경우도 필요함, 광란의 경우 같은 몬스터도 때려야함, 또한 플레이어에게 적대적인 몬스터끼리도 서로 대립 구도가 있을 수도 있기에 서로 공격을 할 경우도 있을텐데 이때 유도탄은 몬스터가 쏜것도 다른 종류의 몬스터에게 적용이 되어야함)

그리고 유도 탄마다 한번 인식 한 후 그 방향으로 직선으로 날아갈것인지 아니면 인식 한 후 적의 위치를 따라갈것인지(예를들어 투사체가 적을 인식하면 그 방향으로 방향을 꺽어 일직선으로 날라갈 것인지 아니면 적이 움직이더라도 부드럽게 코너링을 해서 그 좌표값을 계속 따라 갈것인지)

3. 관통공격 세부내용
관통공격은 하나의 콜라이더에 닿으면 단 한번만 데미지를 줘야함, 같은 콜라이더에 데미지를 2회 이상 주면 안됨

4. 다중발사
투사체를 여러발 날릴때 그 투사체가 한개의 콜라이더에 전부 닿았다면 그 투사체들 각각의 데미지가 들어가야함(예를들어 3발을 쏘는데 3발을 다 하나의 콜라이더에 맞혔다 하면 3발의 데미지가 들어가야함)


[공격속도 세부 내용]
공격속도 계산법은 1초에 몇번을 공격하는지.
무기 및 도구에 공격속도 옵션이 붙어있어야 하며 공격속도가 높아질수록 초당 공격하는 횟수가 많아지는 구조, 예를들어 공격속도가 3일 경우 1초당 3대 때림
그리고 무기 및 도구 및 장비탬 및 셋트옵션 등에 공격속도 가 %로 빨라지는 옵션도 있음
그 경우 공격속도가 3일경우 3의 10%라고 하면 1초당 3.3번을 때림
