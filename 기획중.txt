# 어택모듈 메인 내용
{
[공격 능력치]
1. 물리 공격력 : 공격력 만큼 상대방에게 물리 대미지를 줌, 스테이터스 힘(힘 * 2)과 민첩(민첩 * 1)에 따라 공격력이 추가됨
2. 마법 공격력 : 공격력 만큼 상대방에게 마법 대미지를 줌, 스테이터스 지능(지능 * 3)에 따라 공격력이 추가됨
3. 관통력 : 방어력 - 관통력 으로 방어력 차감 후 받는 피해 감소 계산, 방어력이 음수가 된다면 나누기 2를 한 후 받는피해 감소량 계산(받는 피해가 반대로 늘어남), 민첩에 따라 관통력 증가
4. 크리티컬 확률 : 크리티컬이 터질 확률, 스테이터스 민첩(민첩 * 0.2)에 따라 확률 증가
5. 크리티컬 배수 : 기본값은 175%의 추가 데미지, 아이템등으로 더 올릴 수 있음, 스테이터스 민첩(민첩 * 0.1)에 따라 배수 증가
6. 공격 사거리 : 공격 사거리 수치만큼 공격 범위 변경
7. 공격 속도 : 공격을 얼마나 자주 할 수 있는지의 수치, 스테이터스 민첩에 따라 영향을 줄지는 고려중
8. 히트 수 : 한번 공격할때 몇번을 공격할지, 무기와 스킬로만 히트 수를 정함
9. 생명력 흡수 : 공격 후 임의 캐릭터가 맞았을 경우 공격력의 몇퍼센트 흡수율 만큼 HP를 채움, 무기 스킬 버프로만 올릴 수 있음

* 참고 코드
필요시 static 붙혀서 사용
[SerializeField] private float baseAD = 1f; // 캐릭터 마다 기본 베이스 데미지를 설정
private float attackDamage => isStatus ? baseAD + (isStatus.Strength * 2) + (isStatus.Dexterity) : baseAD; // 스테이터스가 있다면 공식을 사용, 없다면 베이직 공격력
public float viewAttackDamage => attackDamage; // 유아이에서 공격력을 보여줄때 사용

이런식으로 코드 구성 하고 있음, 더 나은 구성이 있다면 지금 참고 코드 구성으로 안해도 됨 수정 허용

* 의도
1. 추후 스테이터스 뿐만 아닌 아이템,버프,패시브 등 여러가지 요소에서 영향을 받을 예정이라 확장성 필요

[몬스터 공격 능력치]
1. 직접 공격 : 몬스터가 공격을
2. 스킬 데미지 : 몬스터가 스킬(패턴)을 발동시킬때 주는 데미지
3. 닿을때 데미지 : 몬스터가 직접공격, 스킬데미지를 주지 않아도 몬스터는 기본적으로 몸에 히트박스가 있음, 닿으면 데미지를 받음, 직접공격과 스킬보다는 약함, 플레이어가 이 히트박스 안에 있다면 1초 마다 데미지를 받음

[참고 사항 & 상세 설정]

1. 물리,마법 공격력
- 플레이어는 스테이터스모듈이 있음 스테이터스에 따른 공격력 변경 시스템이 있음
몬스터는 어텍모듈은 있되 스테이터스모듈이 없을 예정이라 고려해서 제작 필요
- 구성 의도 : 물리와 마법을 나누어둔 이유는 상황에 따라 물리와 마법피해 면역 혹은 대미지감소를 만들어 게임의 다채로움을 만들기 위함


2. 관통력
- 관통력은 방어력 - 관통력 을 한 후 피핵감소량 계산
ex 1) 방어력 20 - 관통력 10 = 방어력 10 으로 디펜스모듈에서 피해감소량 계산
- 방어력 - 관통력 이 음수가 될 경우 나누기 2를 함(피해량 증가량이 너무 높아지는 상황 방지)
ex 2) 공격력 100 일때 관통력 60 - 방어력 10 = 50 / 2 = 25 / (150 + 25) = 0.14 * 공격력 100 = 14의 추가 데미지

디펜스모듈 에 있을 함수 내용 예시
public void DamageReduction(float damage, float penetration)
{
float finalDamage;
float finalDefence;

if (defence < penetration)
{
finalDefence = (( penetration - defence ) / 2 );
finalDamage = damage + ( damage * ( finalDefence / ( 150 + finalDefence )));
}

else if (defence > penetration)
{
finalDefence = defence - penetration;
finalDamage = damage - ( damage * ( finalDefence / ( 150 + finalDefence )));
}

else { finalDamage = damage; } // defence 와 penetration이 같다면 0인것이니 데미지 그대로 전달

return hp.TakeDamage(damage);
}

3. 크리티컬 확률
- 랜덤값은 (0,100) 으로 함
- 만랩까지 전부 민첩에 투자할때 50%의 크리티컬 확률, 나머지는 아이템 및 스킬과 버프로 채우게 할 예정

4. 크리티컬 배율
-민첩을 최대로 찍었을때 25%의 배율 획득하여 총 200% 데미지가 됨, 나머지는 아이템과 패시브 버프로 더 올릴 수 있음
finaldamage = damage * criticalMultiplier;
DamageReduction(finaldamage, penetration);

5. 공격 사거리
공격 방식마다 적용이 다르게 되어야 하기 때문에 아래 공격 방식에서 같이 다룰예정

6. 공격 속도
- 근접 공격의 경우 공격을 더 자주함
- 활의 경우 화살을 더 자주 발사함, 화살의 속도는 변함 없음, 화살의 속도는 투사체 속도로 할 예정
- 마법 공격의 빨라지며 공격을 더 자주함
- 캐스팅이 필요한 것들은 캐스팅 속도가 빨라짐

7. 히트수
- 기본 히트수는 1
- 히트박스가 닿을 경우 히트수에 따라 데미지가 들어감
- 특정 악세사리를 끼면 히트수가 바뀔 수 있음
- 무기마다 히트수가 다를 수 있음
- 스킬마다 히트수가 다를 수 있음

8. 생명력 흡수
- 공격시 데미지를 주었을때 공격력에서 흡수율에 따른 체력회복
float lifeStealAmount = finalDamage * lifeStealPercent;
HP.Heal(lifeStealAmount);

[피격 판정]
투사체에 닿아야함
ex 1) 검의 공격범위가 부채꼴일 경우 검을 부채꼴 범위에서 휘두를때 캐릭터가 공격하는 방향 좌측에서 우측으로 휘두른다면 휘두를때 검에 닿아야 데미지를 받음
ex 2) 창의 공격 범위가 직선일 경우 캐릭터 앞쪽으로 창이 나갈때 창에 닿아야 데미지를 받음
ex 3) 활을 쏜다라고 하면 투사체를 앞으로 발사하는데 발사한 투사체에 닿아야 데미지를 받음
ex 4) 유도공격시 유도 투사체가 타겟을 찾아 따라가다 타겟에게 닿아야 데미지를 받음

즉시 공격
ex 1) 번개 스태프로 공격시 타겟 자동지정 공격으로 타겟에서 즉시 번개를 떨어트려 공격한다면 번개 이팩트가 보일때 바로 데미지까지 받음

[근접] (최상 1점 / 상 2점 / 중상 3점 / 중 4점 / 중하 5점 / 하 6점 / 최하 7점) / 15점 맞추기
1. 부채꼴(예 : 검, 대검) : 데미지 중, 공격속도 중, 관통력 중, 넉백 중상
- 공격 사거리 증가시 각도는 고정이되 r의 길이가 늘어나서 총 면적이 늘어남
2. 직선(예 : 창) : 데미지 중, 공격속도 중상, 관통력 상, 넉백 하
- 공격 사거리 증가시 폭은 그대로, 길이만 늘어남
3. 공격자 앞 범위 공격(예 : 해머) : 공격력 최상, 공격속도 최하, 관통력 상, 넉백 상, 공격 딜레이(클릭하면 모션 뒤 1초뒤 공격 등)  혹은 차징을 만들 예정(3점), 상황에 따라 공격자 앞 범위는 사각형, 혹은 원형
- 공격 사거리 증가시 거리가 늘어난 만큼 원형의 크기가 커짐
4. 공격자 주변 원형(예 : 글레이브, 디아블로의 휠윈드 처럼) : 데미지 중하, 공격속도 최상, 관통력 중, 넉백 중하
- 공격 사거리 증가시 원이 커짐
5. 다중방향 : 직선 공격을 십자모양, 별보양, 삼지창 모양 등 다중방향으로 함

유도탄 같은것도 만들어야함
플레이어가 쏜 유도탄은 체력이 있는 오브잭트와 플레이어를 인식하면 안되고 몬스터들(적)에게만 인식 후 유도하여 날아간 후 데미지를 받아야함
반대로 적이 쏜 유도탄도 체력이 있는 오브잭트와 몬스터들(적)을 인식하면 안되고 유도탄이 인식하는 사정거리 안에 플레이어가 있다면 플레이어에게 유도되어 데미지를 받아야함
다만 유도탄이 죽어라 쫒아가면 안되니 유도탄에 유도 가능 인식 범위와 따른 속도와 지속시간이 있어야함
그리고 유도 탄마다 한번 인식 한 후 그 방향으로 직선으로 날아갈것인지 아니면 인식 한 후 적의 위치를 따라갈것인지(예를들어 투사체가 적을 인식하면 그 방향으로 방향을 꺽어 일직선으로 날라갈 것인지 아니면 적이 움직이더라도 그 좌표값을 계속 따라 갈것인지)

투사체를 여러발 날릴때는 한 투사체가 같은 적의 여러 콜라이더를 건드렸을 때 피해가 여러 번 들어가는 것을 막되 각각의 투사체는 다 데미지가 들어가야함
(예를들어 3발을 쏘는데 3발 다 맞았다 하면 이 3발의 데미지가 들어가야함)

공격속도 계산법은 1초에 몇대를 때리냐 인데
무기 및 도구에 공격속도 옵션이 붙어있어야 하고 공격속도가 높아질수록 초당 공격하는 횟수가 많았으면 좋겠어
그리고 무기 및 도구 및 장비탬 및 셋트옵션 등에 공격속도 가 %로 빨라지는 옵션이 있을 수도 있어

지속딜이 있어(지속딜은 지속시간동안 1초당 한번의 데미지)
화상 데미지는 지속시간 동안 체력퍼센트 데미지이고 지속시간이 7초가 넘어가면 랜덤한 위치로 이리저리 돌아다니며 컨트롤이 불가한 상태가 되도록 했으면 좋겠어, 그리고 다른 지속데미지들과 중복이 되지만 화상데미지 지속시간동안 물데미지가 들어오면 화상데미지는 지속시간이 끝났으면 좋겠어
독데미지는 지속시간 동안 트루데미지였으면 좋겠어, 다른 지속데미지들과 중복이 돼
얼음 데미지는 지속시간동안 행동 불가 하다가 지속시간 끝나면 지속식간에 비례하여 1회 데미지를 받게끔, 얼음데미지 지속시간중에 화상데미지가 들어오면 회상데미지는 안받고 얼음데미지 지속시간이 50% 줄어들었으면 좋겠어
물 데미지는 따로 없지만 몸이 무거워질테니 공격속도와 이동속도 저하인데 지속시간 동안 화상데미지가 들어오면 화상데미지는 안받고 물데미지 지속식간이 절반 감소, 전기데미지가 들어오면 즉시 행동 불능에 막대한 피해를 입고 전기데미지 상태까지 중첩 됐으면 좋겠어, 얼음데미지가 들어오면 물데미지는 사라지고 얼음 지속시간이 150% 증가했으면 좋겠어
전기 데미지는 일반데미지 + 지속시간 동안 데미지를 받으면 추가 데미지 + 일정 데미지 이상 받으면 기절 이였으면 좋겠어
(나는 모든 저항력을 올리면 지속 데미지 감소(데미지가 없는건 지속시간만 감소) + 지속시간 감소 같은 느낌으로 만들거야, 다만 독은 트루데미지여서 독 저항력을 올리면 지속시간만 줄여준다는 컨셉으로 갈거야)

추후에는 독은 해독제를 먹으면 즉시 해제 혹은 패시브 스킬 만독불침 같은걸로 독데미지를 안받는다 등으로 할 예정
화상데미지는 아이템효과(물의 보호막 : 화상데미지를 입지않는다 or 화상데미지의 데미지와 지속시간을 줄여준다)
라는 느낌으로 저항에 관련된 패시브스킬과 아이템효과, 포션 등을 만들꺼야

화살이나 포션등 소모성 아이템은 사용하면 하나씩 줄어들어야해

상태이상도 있어 매혹(지속시간동안 이동속도가 70% 감속된 상태로 플레이어 쪽으로 다가감), 세뇌(지속시간동안 가장 가까운 캐릭터를 공격), 기절, 둔화, 프리징(지속시간동안 아무거또 못함)
